Use `references/vsm-workshop.md` of the scrum-master skill to prepare a value stream mapping workshop for $ARGUMENTS. First do the "Discover the value stream" workflow, for the full ART and for each team. Then write the workshop pack as a Markdown file in `flow-data/`: the problem statement, the attendees, the agenda of four hours, the draft map, the table of stages, the three items to follow (fast, typical and slow, by their anonymous ids), the CFD findings, the questions for the workshop, and the flow accelerators that match the findings. Use only anonymized data in the pack. Ask me for each fact that the data does not give.
