# CLAUDE.md

Instructions for AI assistants that do work in this repository.

## Writing

All documentation, READMEs and skills in this repository use the Strict mode of the
simple-english skill, based on ASD-STE100 Simplified Technical English.

1. Before you write or change a Markdown file, read `.claude/skills/simple-english/SKILL.md`.
2. Write the text with the rules for the document in that skill, in Strict mode.
3. Before you give the change to the owner, do the self-check of that skill, with the Strict
   self-check.
4. Do not change code, identifiers, commands, file paths, headings that other files link to, or
   facts.

This rule applies to new documents and to each change to an existing document. It also applies
to commit messages and pull request descriptions.

Third-party files keep their original text. These are the files that
`skills/scrum-master/scripts/analytics/NOTICE.md` names, and
`.claude/skills/simple-english/SKILL.md`. Do not rewrite them.

## The example project

`example-project/` has its own [CLAUDE.md](example-project/CLAUDE.md). That file gives the
conventions of the fictional product. Its writing rule is the same as the rule in the Writing
section of this file.

## Commits

The repository owner commits. Leave your changes in the working tree for review, unless the
owner asks you to commit or to open a pull request.
